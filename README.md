# WebScroll — Клон социальной сети Pinterest (Fullstack)

Веб-приложение с клиент-серверной архитектурой, предназначенное для публикации, просмотра и обмена графическим контентом (изображениями и GIF-анимациями). Проект разработан в рамках изучения современных веб-технологий и реализации полноценного взаимодействия между Frontend и Backend слоями.

## 🛠 Технологический стек

### Frontend:
* **Фреймворк:** Vue.js (Single Page Application)
* **Инструменты сборки:** Vite
* **Маршрутизация:** Vue Router (реализованы переходы между страницами авторизации, регистрации и загрузки контента)
* **Языки:** JavaScript / HTML5 / CSS3

### Backend & Database:
* **Платформа:** Node.js
* **База данных:** SQLite (для хранения данных пользователей и метаданных постов)
* **Архитектура хранения:** Реализован классический паттерн разделения данных: тяжелые статические медиафайлы сохраняются в изолированную директорию на сервере (`uploads`), а в БД записываются уникальные пути к ним, что оптимизирует производительность запросов.
* **Протоколы:** WebSocket (для мгновенной синхронизации лайков и комментариев между пользователями в реальном времени).

## 🚀 Реализованный функционал

* **Аутентификация пользователей:** Полноценные страницы регистрации (`RegistrationPage.vue`) и авторизации (`AuthPage.vue`) с валидацией данных.
* **Менеджмент контента:** Возможность загрузки изображений и GIF-файлов на сервер через интерфейс (`Upload.vue`).
* **Динамическая лента:** Отображение загруженных медиафайлов в виде интерактивной сетки постов с динамическим подтягиванием данных с бэкенда.
* **Интерактивный просмотр:** Модальное окно с детальной информацией о посте, списком лайкнувших пользователей и системой комментирования.

## 📝 Статус проекта
Это учебный пет-проект, созданный для отработки навыков проектирования баз данных, работы с REST API, WebSocket и построения SPA-приложений. Фокус был направлен на реализацию бизнес-логики и корректную работу клиент-серверной части.
